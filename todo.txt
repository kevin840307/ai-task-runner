AI Task Runner - Future 實作 TODO
================================

重建日期：2026-10-17
分支：feature/ui
依據：根目錄 future.txt（2026-10-17 新版）

目的
----
這份 todo.txt 是依照新版 future.txt 重新打造的中文實作清單。
舊版 minimal-closed-loop-runtime TODO 視為舊 roadmap，不再拿來驅動這一輪 Future Chat / Task / Worktree / Merge 開發。

最高原則
--------
[ ] Runner Core 仍是 Workflow / Stage / retry / recovery / resume / runtime truth 的唯一權威。
[ ] Chat 不得為了方便直接塞進 FlowEngine / StageExecutor。
[ ] Chat Queue 與 Runner Task Queue/ordered items 完全分離。
[ ] Ask/Question 是 Chat Agent interaction，不得污染 RunState / retry / recovery。
[ ] UI disabled 只是 UX；所有 destructive / transition action 後端仍需 fail-closed guard。
[ ] Main workspace 永久保留；Worktree 是可選隔離。
[ ] Task 完成不自動 Merge。
[ ] Merge/Conflict 不進 Runner recovery state machine。
[ ] 任何會影響 24H runtime 的修改都要補 deterministic/mock/live regression。
[ ] 正式 UI 不准把 Qwen/OpenCode 的 capabilities/models/skills 寫死在 frontend。
[ ] Prototype 可以 mock，但 Mock 必須使用跟 production 相同的 schema。
[ ] 新功能完成後移除舊 handler / duplicate wrapper，不保留平行 contract。

PHASE 1 - 共用 Agent Capability 層
=================================

目標
----
正式 UI 只能向 backend 問「這個 Agent 現在能做什麼」，不能理解 Qwen/OpenCode 內部細節。

1.1 共用 capability schema
-------------------------
[ ] 在 runner/agent 共用層新增/整理 Agent capability schema。
[ ] schema 至少包含：
    - agent id / display name
    - available models
    - permission/mode profiles
    - slash commands
    - user-invocable skills
    - capability source（builtin / skill / command / extension / project / user）
    - Ask/question support
    - streaming support
    - cancel support
    - queue/steer support（若 native 有）
[ ] capability 只描述能力，不保存 Chat session 狀態。
[ ] 保留現有 AgentBackend.ask() 給 Runner 執行用途，不把 Chat session state 塞進 BaseBackend。
[ ] 評估新增 ChatAgentAdapter 或 thin interactive adapter，重用 runner/agent 的 command/model discovery。
[ ] 避免 BaseBackend 變成超大型 God object。

1.2 Qwen adapter
----------------
[ ] runner/agent/qwen.py 正式取得 model list，沿用/整理現在 available_models()。
[ ] capability discovery 參考 Qwen 自己的 slash command registry / SkillManager。
[ ] 支援 project/user/extension/bundled Skills 的可見性。
[ ] 尊重 user-invocable / disabled slash command / disabled skill 規則。
[ ] / palette 要能看到 user-invocable Skill 的 /<skill-name>。
[ ] extension skill 名稱保留 namespace（例如 owner:name）。
[ ] Qwen Mode mapping：
    - Read -> plan/read-only
    - Auto -> auto
    - YOLO -> yolo
[ ] 若實際 Qwen 版本不支援某 mode，capability 回 unavailable，不可 frontend 假裝支援。
[ ] Ask 對接 ask_user_question：
    questions[] -> UI -> answers[index] -> 回原 tool call。
[ ] Queue 若採 application-level，仍可提供 Ctrl+Q UX；不必依賴 CLI native queue 實作。

1.3 OpenCode adapter
--------------------
[ ] runner/agent/opencode.py 正式取得 provider/model list。
[ ] / palette capability 來源：
    - built-in commands
    - .opencode/commands

    - slash-enabled SKILL.md
[ ] Skill discovery 尊重 OpenCode project/global/compatible skill locations與 permission。
[ ] Mode mapping：
    - Read -> deny write/edit/shell/task mutation
    - Auto -> normal safe permission profile
    - YOLO -> allow-all equivalent（只有實際支援才 expose）
[ ] Question tool 正規化成共用 Ask schema。
[ ] 不把 OpenCode permission JSON 直接暴露給 frontend。

PHASE 3 - Chat Queue
====================

產品行為
--------
[ ] Agent active turn 時允許加入 queued prompts。
[ ] 顯示位置固定在 Composer 上方。
[ ] 沒 Queue 時完全隱藏。
[ ] FIFO。
[ ] 每筆可 Edit。
[ ] 每筆可 Delete。
[ ] Edit/Delete 必須有 item id/version，防止 stale UI 修改錯筆。
[ ] Queue 是 session-scoped。
[ ] Queue 不等於 Task List。
[ ] Queue 不會建立 Runner Task。

Backend
-------
[ ] POST /api/chat/sessions/{session}/queue
[ ] PATCH /api/chat/sessions/{session}/queue/{item}
[ ] DELETE /api/chat/sessions/{session}/queue/{item}
[ ] GET queue projection 可併進 session projection。
[ ] current turn 完成後由 Chat service 取下一筆。
[ ] process restart 時定義 queue persistence：
    - pending 保留
    - executing item 依 turn state 決定 recovered/failed
[ ] 不使用 Runner retry/recovery 去恢復 Chat Queue。

快捷鍵
------
[ ] Ctrl+Q 明確 enqueue（參考 Qwen Code UX）。
[ ] Enter 的 active-turn 行為要明確：
    - steer current turn 或
    - queue
    先選一個產品規則，不可 agent 各自偷偷不同。
[ ] 如果 Agent native 行為不同，由 adapter 映射。

測試
----
[ ] enqueue 1/多筆。
[ ] edit。
[ ] delete。
[ ] FIFO consume。
[ ] active turn cancel。
[ ] reconnect queue 保留。
[ ] stale edit/delete fail closed。
