Read project/input/configs and replace the repeated configuration files with a compact reusable template system.

Requirements:
- Create project/template/config.ini.j2.
- Create project/values.yaml containing only values that differ between generated files.
- values.yaml must contain at most 24 non-empty lines. Keep every line at most 160 characters.
- Create project/render.py using Python.
- Running `python render.py` from the project root must recreate every original file under output/configs.
- Rendered filenames, text, comments, blank lines, ordering, and final newline must match input/configs byte-for-byte.
- Keep shared text in the template instead of duplicating complete configs in values.yaml or render.py.
